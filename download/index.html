iPhone・iPad

兩種裝法，自己選

方案 A · 推薦

加入主屏幕（不用簽名）

  1. 用 Safari 打開本站
    一定要 Safari，Chrome 或 IG／FB 內建瀏覽器不行。
  2. 點底部「分享」按鈕（方框加上箭頭的圖標），往下滑找到 「加入主屏幕」。
  3. 按「加入」，主屏幕就多一個 選購顧問圖標。之後點它會全屏打開，像原生 App 一樣。

優點：永久有效、不用電腦、不會過期。加完之後即使沒有網路，開過的頁面也能看。

方案 B · 真正的 App

下載 .ipa 自己簽名

  1. 電腦裝 愛思助手（i4.cn）、Sideloadly 或 AltStore，用 USB 線連上 iPhone。
  2. 把上面下載的 Apple-Hub-1.1.0-ios.ipa 拖進工具，輸入自己的 Apple ID（免費帳號就行）。
  3. 工具自動簽名並安裝。首次開啟前，到 iPhone 設定 → 通用 → VPN 與裝置管理 點「信任」你的開發者憑證。
  4. 完成。免費簽名 7 天後失效，用同一個工具再簽一次即可，App 裡的資料會保留。

優點：真正的獨立 App，有圖標、全屏、可背景快取。缺點：每 7 天要重簽一次（付費開發者帳號可延長到一年）。

ipa 是什麼？安全嗎？

就是 iPhone 的安裝包，本質是一個 zip：裡面是 App 的程式檔、圖標，加上這 9 個工具的網頁。這個 ipa 是我用 Apple 官方 iOS SDK 編譯的，沒有連網上傳、沒有廣告 SDK、沒有第三方追蹤。

因為沒有付費開發者憑證，檔案是未簽名的——iOS 不會讓你直接裝，必須先用自己的 Apple ID 簽一次（就是上面方案 B 做的事）。這也是為什麼頁面上給了 SHA-256：你可以確認檔案沒被別人改過。

手機與電視怎麼裝

📱 Android 手機 / 平板

  1. 點上面的下載按鈕，等通知欄出現 Apple-Hub-1.1.0-android.apk。
  2. 點開通知，系統會問「是否允許安裝未知應用」→ 選 允許（在設定裡叫「安裝不明應用程式」）。
  3. 按 安裝 → 開啟。之後從桌面圖標就能進。

華為、小米、OPPO 等機型可能在安裝時多一道「安全檢測」，選「繼續安裝」即可。

📺 Android TV / 電視盒

  1. 把 APK 放進 U 盤，插到電視上；或用電視上的「文件管理／媒體播放器」開啟 U 盤。
  2. 點 APK 安裝。若被攔截，先到 設定 → 安全性 → 不明的來源 打開。
  3. 從應用列表找到 選購顧問 TV（有橫式封面圖）。用遙控器上下鍵翻頁、按確定鍵點擊。

進階：同網段電腦可執行 adb install Apple-Hub-1.1.0-androidtv.apk 直接推送到電視。

電腦安裝

macOS 與 Windows

macOS

  1. 下載 .dmg，雙擊打開，把 選購顧問 圖示拖進「應用程式」資料夾。
  2. 第一次別直接雙擊——在「應用程式」裡 右鍵（或按住 Control 點擊）→ 打開，在警告視窗再按一次「打開」。
  3. 之後就正常雙擊即可。
    若顯示「已損毀」：到「系統設定 → 隱私權與安全性」最下方按「仍要打開」。

Windows

  1. 下載 .zip，右鍵 → 解壓縮全部（不要直接在壓縮檔裡雙擊）。
  2. 進入解壓後的資料夾，雙擊 選購顧問.exe。
  3. 出現藍色 SmartScreen 視窗時，點 「更多資訊」→「仍要執行」。
    只需一次；之後可把 exe 傳送到桌面當捷徑。
五個版本都沒有付費簽章（個人專案沒買 Apple Developer / Windows 憑證），所以第一次打開會被系統攔一下——這是正常現象，不是病毒。照上面的步驟做一次就好，之後不會再問。

常見問題

下載前想知道的事

為什麼 ipa 要自己簽名？7 天後怎麼辦？

iOS 只安裝「由 Apple 認可的憑證簽過名」的 App。憑證是綁定在個人 Apple 帳號上的，我不能代替你簽（簽了也裝不進你的手機）。所以流程是：你下載 ipa → 用愛思助手／Sideloadly 拖進去 → 輸入自己的 Apple ID → 工具自動重簽並安裝。免費帳號的簽名有效期 7 天，到期後用同一個工具再簽一次就好，App 內的資料（推薦結果、殘值估算紀錄）會保留。

App 裡面有哪 9 個工具？

選機問答（推薦機型）、Apple 產品總覽（四種幣別）、規格對比、換機指南、訂閱比價、相容性查詢、殘值估算、分期試算、Apple 年表。桌面版側邊欄點一下就切換，也可以用 ⌘K / Ctrl+K 搜尋。

Android 手機會不會有病毒？

APK 是我用 Android 官方 build-tools 編譯、自己簽名的，內容就是這 9 個工具的頁面加一個 WebView 外殼，沒有連網權限以外的任何權限。頁面上有 SHA-256，你可以自行比對檔案是否被動過。

電視版遙控器怎麼操作？

上下鍵翻頁、確定鍵點擊連結、返回鍵回上一頁。字體與卡片都為大螢幕放大過，三公尺外也看得清。

會自動更新嗎？

不會。有新版本時回來這一頁重新下載、覆蓋安裝即可，本機資料會保留。

怎麼確認下載的檔案沒被動過？

點卡片上的 SHA-256 那行可複製雜湊值，然後在終端機執行 shasum -a 256 檔案路徑（Windows 用 certutil -hashfile 檔案 SHA256），兩串字完全一樣就代表檔案完整。
